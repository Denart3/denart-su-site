Персональный домен Дениса Артамонова. Личный проект, не коммерческий сервис.

Назначение

Домен используется для личного приложения автоматизации, которое работает на моём собственном сервере и обслуживает одного пользователя — владельца аккаунта. Приложение помогает обрабатывать почту, файлы и календарь владельца и не предназначено для других пользователей.

Что делает приложение

  • Читает и сортирует входящую почту владельца по заданным правилам.
  • Работает с файлами и документами владельца в его облачном хранилище.
  • Формирует напоминания и заметки по событиям владельца.

Чего приложение не делает

  • Не передаёт и не продаёт данные третьим лицам.
  • Не используется для рассылок, рекламы или сбора данных других людей.
  • Не предоставляет доступ к аккаунту владельца кому-либо ещё.
